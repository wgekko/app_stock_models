# Quant Platform: Terminal de Análisis & IA

La **Quant Platform** es una herramienta de análisis financiero de alto rendimiento diseñada para traders cuantitativos, analistas de datos y entusiastas de las finanzas algorítmicas. Esta plataforma integra cálculos matemáticos avanzados, modelos de Deep Learning y técnicas de gestión de riesgo en una interfaz web moderna y reactiva.

## Características Principales

* **Motor de Cálculo Financiero**: Utiliza `Polars` para un procesamiento de datos ultra rápido, calculando derivadas financieras, osciladores técnicos (RSI, Estocástico) y Bandas de Bollinger.
* **Análisis Estocástico**: Implementación de las Griegas (Delta/Gamma) mediante el modelo Black-Scholes para la evaluación de derivados.
* **Inteligencia Artificial Integrada**:
    * **LSTM (Long Short-Term Memory)**: Modelos de redes neuronales para la predicción de series temporales de precios.
    * **XGBoost**: Clasificación de tendencias mediante el análisis de la interacción de indicadores técnicos.
    * **GARCH(1,1)**: Modelado de heterocedasticidad para proyectar la volatilidad futura y el riesgo de mercado.
* **Dashboard Interactivo**: Visualizaciones dinámicas construidas con `Plotly` para una experiencia de usuario fluida.

## Tecnologías Utilizadas

* **Framework**: [Streamlit](https://streamlit.io/)
* **Manipulación de Datos**: `Polars`, `Pandas`, `NumPy`
* **Machine Learning/DL**: `TensorFlow` (Keras), `XGBoost`, `Scikit-Learn`
* **Finanzas**: `yFinance`, `Arch`
* **Visualización**: `Plotly`
